# ADAPT-NK Target Screening Pipeline

This repository describes a gene selection pipeline from public data by Netskar et al. (2024) used as a PhD concept note supplementary file by Richard Suteja

**Citation**

The public data was obtained from:

Netskar, H., Pfefferle, A., Goodridge, J.P. et al. Pan-cancer profiling of tumor-infiltrating natural killer cells through transcriptional reference mapping. Nat Immunol (2024). https://doi.org/10.1038/s41590-024-01884-z
